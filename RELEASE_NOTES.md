Una sola copia di Claude Live per Mac: la seconda si accorge della prima e si chiude, invece di litigarci.

- **Due copie accese insieme facevano danni che sembravano difetti dell'app.** Condividono lo stesso file di impostazioni, quindi l'ultima che salva vince e le preferenze sembrano cambiare da sole; ognuna manda le proprie notifiche e disegna il proprio notch. E soprattutto: ognuna chiede a VS Code la lista delle finestre con `code --status` — la cosa che fa comparire per un istante una seconda icona di VS Code nel Dock — e **non può riconoscere la domanda dell'altra**, perché il filtro contro l'auto-innesco conosce solo i propri comandi. Così ognuna prendeva la domanda dell'altra per un avvio vero di VS Code e richiedeva: icona lampeggiante ogni pochi secondi, all'infinito.
- **Ora la seconda copia si chiude da sola** e chiede alla prima di mostrarsi, così lanciarla non sembra che non abbia fatto niente. Confronta le date di avvio invece di limitarsi a chiedere «c'è qualcun altro?»: due copie lanciate insieme si vedrebbero a vicenda e si chiuderebbero entrambe.
- **Chi sviluppa l'app può ancora tenerne due** di proposito, con `CLAUDELIVE_ALLOW_SECOND_INSTANCE=1`.
- La copia che si fa da parte **non tocca niente di condiviso** uscendo: in particolare non cancella il file di heartbeat degli hook, che appartiene alla copia che resta e senza il quale Claude Code smette di aspettare le risposte dal pannello.
- L'evento finisce nel log anche a log di debug spento: senza una traccia su disco, il sintomo — un'icona che lampeggia nel Dock — non porta a nessuna spiegazione.
