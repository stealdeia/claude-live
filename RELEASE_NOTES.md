Le percentuali si aggiornano anche se lavori dall'app Claude invece che da VS Code.

- **Il problema.** Il token che Vibing Code Live usa per leggere l'utilizzo lo rinnova solo Claude Code nel Terminale o in VS Code. Il Claude Code dentro l'app Claude non lo tocca: chi lavora da lì vedeva le percentuali fermarsi dopo 8 ore, con «Token scaduto».
- **La soluzione: un token tutto per l'app.** Impostazioni → Claude Code → «Token per l'utilizzo» → **Crea token…**. Si apre il Terminale, accedi nel browser, copi il token che compare e lo incolli nel campo. Dura un anno e non scade se non usi il Terminale.
- **Serve solo a chi usa l'app Claude.** Chi lavora da VS Code o dal Terminale non deve fare nulla.
- **Ti avvisa lui.** Quando le percentuali si fermano per un token scaduto, la notifica e la voce nel menu portano dritte alla sezione giusta.
- Il token di Claude Code resta in sola lettura: l'app non lo rinnova mai, quindi non può scollegarti dal tuo account.
